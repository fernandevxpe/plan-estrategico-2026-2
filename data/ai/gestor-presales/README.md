# Gestor IA — Pré-vendas

Cada arquivo `AAAA-MM-DD.json` é uma análise congelada dos fatos disponíveis na data.
As edições antigas não devem ser sobrescritas: elas permitem comparar o diagnóstico com o resultado posterior.

O texto pode interpretar os indicadores, mas não deve inventar objetivos, objeções, perfil, qualificação,
autoria humana ou conversão individual quando esses campos não existirem nos dados processados.
